## Switch in 3 steps

1. Download `portable_crealityprint.exe` from the [Portable Starter release](https://github.com/sorglos-it/portable-starter/releases/latest).
2. Copy it into your Creality Print folder, next to `CrealityPrint.exe`.
3. Double-click it. Your `profile` folder stays in use – `CrealityPrintPortableStarter.exe` is no longer needed.

The old `CrealityPrintPortableStarter.exe` stays available on the [Releases](../../releases) page of this repository.
